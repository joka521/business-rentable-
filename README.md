# Atelier Visible

Site vitrine de pré-lancement pour une offre de création de sites web et d'amélioration de présence en ligne destinée aux artisans et petites entreprises.

## État du projet

- Version statique HTML/CSS/JS, sans dépendance ni build.
- Offre test : pack lancement à 490 € et suivi optionnel à 39 €/mois.
- Formulaire en mode prévisualisation : il ouvre un e-mail après configuration de `CONTACT_EMAIL` dans `index.html`.
- Les prix, le périmètre et les conditions doivent être confirmés avant toute vente.
- Les mentions légales, la politique de confidentialité, l'identité commerciale et les coordonnées doivent être complétées avant publication.

## Mise en ligne

Activer GitHub Pages sur la branche `main`, dossier `/ (root)`.

## Avant commercialisation

1. Choisir et vérifier le nom commercial.
2. Configurer une adresse e-mail réelle et le formulaire.
3. Ajouter les mentions légales et la politique de confidentialité.
4. Rédiger un devis/contrat avec périmètre, délais, paiement, propriété du domaine et conditions de maintenance.
5. Vérifier les obligations de création d'entreprise et de facturation avant de commencer à facturer.

Ce dépôt ne constitue pas une promesse de résultats commerciaux. Aucun classement Google ou volume de clients n'est garanti.
